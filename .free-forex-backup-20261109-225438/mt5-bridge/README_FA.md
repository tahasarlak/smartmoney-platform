# راهنمای Bridge ویندوزی TRADF / MT5

این سرویس فقط داده بازار را از ترمینال MetaTrader 5 که از قبل به حساب DEMO وارد شده دریافت می‌کند. این سرویس سفارش معاملاتی ارسال نمی‌کند.

## پیش‌نیاز
- Windows 10/11 نسخه 64-bit
- MetaTrader 5 نصب‌شده و واردشده به حساب Demo
- Python 3.12 نسخه 64-bit
- آدرس HTTPS سرویس TRADF روی Render
- توکن مشترک که فقط در Render و فایل `.env` محلی Bridge قرار می‌گیرد

## اجرا
فایل `.env.example` را به `.env` کپی و مقادیر لازم را تنظیم کن، سپس:

```powershell
.\run_bridge.ps1
```

برای اجرای خودکار پس از ورود به ویندوز (اختیاری و پس از تست دستی):

```powershell
.\install_task.ps1
```

اگر بروکر از نام‌هایی مانند `EURUSD.a` یا `GOLD` استفاده می‌کند، `MT5_SYMBOL_MAP` را در `.env` تنظیم کن. نام‌های واقعی نماد را از Market Watch ترمینال بررسی کن.

Bridge در شروع تاریخچه را همگام می‌کند و سپس هر ۳۰ ثانیه کندل‌های جدید را می‌فرستد. برای دوره ۲۱ روزه M5، ۷۰۰۰ کندل اولیه حدود ۲۴ روز داده را پوشش می‌دهد؛ این مقدار به تاریخچه‌ای بستگی دارد که ترمینال بروکر در اختیار گذاشته است.

هرگز فایل `.env` را commit نکن و توکن را در پیام یا تصویر ترمینال ارسال نکن.
